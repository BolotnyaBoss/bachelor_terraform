## Overview
The `docs` folder serves as the centralized documentation repository for the Terraform infrastructure project. Its primary purpose is to provide detailed explanations and usage instructions for the Terraform configuration files and modules contained within the project. This folder plays a crucial role in supporting developers, DevOps engineers, and other stakeholders by offering clear, structured insights into the infrastructure components, their configuration variables, outputs, and the overall architecture.

The project structure documented here reflects a modular Terraform-based approach to managing cloud infrastructure, specifically targeting Azure resources. It contains markdown documentation for the main Terraform entry files (`main.tf.md` and `variables.tf.md`) as well as for individual reusable modules housed within the `modules` subfolder. This enables better maintainability, reusability, and understanding of the infrastructure-as-code managed resources.

## Usage
To utilize the documentation in this folder for effective infrastructure management:

1. Begin with `main.tf.md` and `variables.tf.md` to understand the root-level Terraform configuration and the variables required to run the infrastructure deployment.
2. Navigate into the `modules` subfolder documentation to understand each individual reusable component:
   - Resource Group: foundational Azure resource grouping
   - Storage Account: scalable and secure storage components
   - Data Factory: orchestration and data integration pipelines
   - SQL Server and SQL Database: managed database infrastructure supporting application data layers
3. Each module folder contains detailed README files that explain the purpose, input variables, output parameters, and example usage scenarios.
4. Refer to the `variables.tf.md` files to identify required variables and configure them accordingly in your Terraform workspace before deployment.
5. Use the outputs documented in `outputs.tf.md` to link resources between modules or to provide useful information post-deployment.

By following the documentation, users can gain a comprehensive understanding of the Terraform codebase, customize deployments to their environment, and integrate the infrastructure modules efficiently within their projects.

## Useful details
- The modular structure promotes reuse and simplifies future enhancements or changes to parts of the infrastructure without impacting unrelated components.
- Detailed comments and markdown files for variables and outputs ensure transparency about resource dependencies and parameters.
- The documentation supports a best-practice approach to infrastructure automation by aligning with Terraform module usage guidelines and Azure best practices.
- This docs folder should be updated alongside any changes to Terraform code to keep infrastructure documentation accurate and current.
- It helps onboard new team members quickly by providing a structured understanding of the project's infrastructure design.
