## Overview
The `resource-group` folder contains Terraform configuration files to provision and manage an Azure Resource Group within an infrastructure-as-code project. Azure Resource Groups serve as logical containers that group related Azure resources for simplified management, deployment, and access control. This folder's configurations enable consistent creation and configuration of a resource group, providing a foundational building block for larger cloud infrastructure deployments.

By modularizing resource group creation here, this component promotes reuse, standardization, and clean separation of concerns within a broader Terraform codebase. Other modules and resources can reference the outputs from this folder to associate resources with the defined resource group dynamically.

## Usage
To use the resource group module within a Terraform project:

1. Ensure Terraform is installed and configured with access to your Azure subscription (via Azure CLI or service principal credentials).
2. Instantiate the module by referencing this folder in your Terraform configuration:

```hcl
module "resource_group" {
  source = "./modules/resource-group"

  resource_group_name     = "myResourceGroup"
  resource_group_location = "eastus"
}
```

3. Customize input variables (`resource_group_name` and `resource_group_location`) to match your naming conventions and required Azure region.
4. Run Terraform commands as usual:
   - `terraform init` to initialize the working directory.
   - `terraform plan` to preview infrastructure changes.
   - `terraform apply` to provision the Azure resource group.
5. Use exported outputs (`resource_group_name`, `resource_group_location`) from this module as inputs when provisioning other dependent Azure resources.

## Useful details
- **main.tf**: Defines the Azure Resource Group resource (`azurerm_resource_group`) with a fixed default location (`eastus`) unless overridden by a variable.
- **variables.tf**: Declares inputs controlling the resource group’s name and location, facilitating parameterization and flexibility.
- **outputs.tf**: Exposes important metadata — such as the resource group's name and location — to enable other Terraform modules to integrate with it smoothly.
- This module assumes Terraform and the AzureRM provider are properly installed and configured beforehand.
- The fixed location default is set to `eastus` but can be customized by setting the `resource_group_location` variable.
- Following this modular approach helps maintain a clear and manageable Terraform codebase, especially for multi-resource Azure deployments.
