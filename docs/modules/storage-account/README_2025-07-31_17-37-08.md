## Overview

The `storage-account` folder contains Terraform infrastructure-as-code configurations designed to provision and manage Azure Storage resources. Its primary functionality involves setting up a Storage Account, Storage Container, and Storage Blob, which serve as scalable cloud storage solutions within the Azure ecosystem.

This module plays a vital role in automating cloud infrastructure deployments, ensuring consistent, repeatable, and version-controlled provisioning of storage assets required by broader application environments. Typical use cases include storing application data, holding backups, or serving as intermediary storage for data pipelines.

The folder is organized into multiple Terraform configuration files, each responsible for a particular aspect of the infrastructure definition:

- `main.tf.md`: Core provisioning logic for storage resources.
- `variables.tf.md`: Input parameters defining configurable attributes for the resources.
- `outputs.tf.md`: Output variables exposing critical resource information after deployment.

Together, these files make the module modular, reusable, and maintainable, fitting seamlessly into larger infrastructure projects.

## Usage

To use the `storage-account` module in your Terraform project:

1. **Declare the Module**

   Add the following block in your Terraform configuration to instantiate the module and supply necessary input parameters:

   ```hcl
   module "storage_account" {
     source = "./modules/storage-account"
     
     # Provide required input variables: 
     resource_group_name = "<your-resource-group>"
     location            = "<azure-region>"
     storage_account_name = "<desired-storage-account-name>"
     container_name      = "<container-name>"
     blob_name           = "<blob-name>"
     # other variables as defined in variables.tf.md
   }
   ```

2. **Initialize Terraform**

   Run:

   ```
   terraform init
   ```

   This initializes the working directory and downloads necessary providers.

3. **Plan and Apply**

   Execute:

   ```
   terraform plan
   terraform apply
   ```

   This will provision the Azure Storage resources as defined.

4. **Utilize Outputs**

   After apply, the module outputs can be referenced to retrieve the storage account’s primary access key and other essential details for use in dependent modules or applications.

## Useful details

- **Separation of Concerns:** The three main files (`variables.tf.md`, `main.tf.md`, `outputs.tf.md`) split the code logically into input configurations, resource provisioning, and outputs, simplifying maintenance and understanding.

- **Security Considerations:** The storage account access key, defined as an output variable, should be handled carefully to avoid exposure of sensitive keys. It is recommended to use secrets management or environment-specific secure storage when consuming this output.

- **Extensibility:** The module can be extended by adding more resources or parameters in the respective Terraform files, supporting advanced configuration scenarios such as network rules, encryption, or lifecycle policies.

- **Idempotent Infrastructure:** Running Terraform multiple times with unchanged variables will not modify the storage resources, promoting safe repeatable deployments.

This module is intended to be a foundational component of Azure infrastructure projects requiring durable and manageable storage solutions deployed via Terraform.
