## Overview
The `sql-database` module contains infrastructure as code components designed to provision and configure an Azure SQL database as part of a cloud deployment project. This module leverages Terraform to define an `azurerm_mssql_database` resource on an existing Azure SQL Server, automating the setup of the database with specific SKU and collation settings.

A key feature of this module is its ability to import an existing database schema and data from a BACPAC file stored in an Azure Blob Storage container, enabling seamless initialization or restoration of the database as part of automated infrastructure provisioning.

This folder and its components form a critical part of a larger cloud infrastructure project, where managing database lifecycle, configuration, and state consistency is required for operational stability and repeatable deployments of database-dependent applications.

## Usage
1. **Set variables:** Customize and provide values for the input variables defined in `variables.tf.md`. These variables specify database configuration details (name, collation, SKU) and storage account parameters pointing to the BACPAC file location.

2. **Provision the database:** Apply the Terraform configuration (`main.tf.md`) within your Terraform workspace. This will create or update the Azure SQL database resource on the specified Azure SQL Server.

3. **Database import:** Upon provisioning, the module triggers an import operation that loads the database schema and data from the specified BACPAC file in Azure Blob Storage, initializing the database to the desired state.

4. **Integration:** Use this module as part of your overall Terraform deployment workflow alongside other infrastructure modules (e.g., virtual networks, application services) to provide a provisioned, ready-to-use SQL database backend.

## Useful details
- The module assumes that the target Azure SQL Server already exists and is accessible with appropriate permissions.
- SKU and collation settings can be customized to meet application requirements.
- The import from BACPAC supports database schema migration and seed data population within the infrastructure provisioning process, minimizing separate database deployment steps.
- Error handling and import status are tied to Terraform's apply lifecycle events.
- This module can be extended or parameterized further to accommodate advanced SQL Server features like geo-replication or auditing by modifying the Terraform definitions accordingly.
